# praisetc.com

Static portfolio and company site of PRAISE THE CODE, published by GitHub Pages from the root of `main` at https://praisetc.com/ (custom domain in `CNAME`).

## Pages

- `index.html`: Studio overview, language constellations, contact links and registration details.
- `projects/dawnbringer/index.html`: Dawnbringer architecture, verification pipeline and Votive Gothic art direction.
- `projects/openstrut/index.html`: OpenStrut V2 dual-code engine, 25 KB IFC4 writer and 2D/3D engineering plates.
- `projects/engineering/index.html`: Studio engineering rules, performance architecture and Terminal PTC visual system.

## Assets

Hand-written HTML, one shared stylesheet (`assets/site.css`), one deferred script (`assets/site.js`), dark and light SVG diagrams in `assets/diagrams/` and optimized WebP plates in `assets/showcase/`. No bundler, no framework and no external requests.
