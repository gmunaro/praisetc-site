02 // Rules

Four engineering rules

Each rule states what it prevents and what it buys.

Rule 01

Deterministic cores

  • Battles use an integer clock and no random calls, so a fight replays identically on any device.
  • Sound effects use a seeded generator, so a seed always rebuilds the same file.

Rule 02

Independent oracles

  • OpenStrut checks against UNESP worked examples and the 1991 binary, so a wrong formula cannot pass.
  • Dawnbringer art tests fail any backdrop colour outside the locked palette.

Rule 03

Explicit byte budgets

  • IFC export adds 25 KB, fetched on demand, where web-ifc needs a 1.6 MB download.
  • Sound is synthesized, not sampled, to halve its share of the 12 MB web budget.

Rule 04

Generated assets

  • Brand SVGs and PNGs rebuild from the colour tokens, so one edit updates the set.
  • Dawnbringer sprites are redrawn at 2x by generators, never upscaled, so pixels stay crisp.
