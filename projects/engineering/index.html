02 // Principles

Four rules, with evidence

Rule 01

Same input, same output

  • Dawnbringer's battle simulation runs on an integer clock (TICKS = 5342931457063200) with no random number generator in game/core/battle/.
  • gen_sfx.py uses its own seeded generator, never the system RNG, so a seed always writes the same sound.
  • OpenStrut gives each IFC element a deterministic 128-bit GlobalId, so a re-export keeps BCF comments attached.

Rule 02

Test against an oracle the code did not produce

  • OpenStrut's expected values come from Prof. Paulo Bastos' published examples (UNESP), hand calculations, numerical integration or the 1991 SISTRUT binary in DOSBox-X.
  • Its IFC files roundtrip through IfcOpenShell, web-ifc and @ifc-lite/parser.
  • Dawnbringer's art tests check backdrops against palette.json, the written 32-colour spec.

Rule 03

Every format has a byte budget

  • OpenStrut's IFC4 writer is 25.0 KB (10.0 KB gzip) where web-ifc ships a 1.6 MB .wasm.
  • gen_sfx.py cites a 12 MB budget for the web build.
  • This site: one stylesheet, one script, no webfont. The numbers are in the next section.

Rule 04

Rebuild from source, pin what you cannot rebuild

  • Dawnbringer's CI pins Godot 4.5-stable and checks its SHA-512 before any test runs.
  • gerar_praisetc_svg.mjs regenerates the brand's 14 SVGs and 23 PNGs from tokens.json and fails on a wrong size or a text outside the safe area.
  • OpenStrut's bun run check chains route generation, tsc, oxlint, oxfmt and Vitest.

03 // This site

Performance architecture of praisetc.com

The page you are reading is the test case. Each decision below has a reason you can check in the page source.

Frameworks
0. Hand-written HTML, one site.css and one deferred site.js with no dependency.
Fonts
0 webfonts. Segoe UI, Inter or the system sans; Cascadia Mono, JetBrains Mono or the system mono.
Third parties
0 requests. No analytics, no CDN, no embed, no tracking pixel.
Navigation
Speculation Rules with prerender and moderate eagerness: hovering a link starts rendering the next page.
Layout
Every <img> declares its width and height, so the browser reserves space before the file arrives.
Rendering
content-visibility: auto skips sections below the fold on first paint. Animations touch only transform and opacity and stop under prefers-reduced-motion.
Theme
A 120-byte inline script applies the saved theme before first paint. Diagrams ship as dark and light SVG pairs, so a switch makes no request.
